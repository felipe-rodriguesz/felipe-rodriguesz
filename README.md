Reúno aqui projetos acadêmicos e experimentais de desenvolvimento de software e sistemas, com trabalhos de backend e web, compiladores e arquitetura de computadores.

## Interesses

Backend e aplicações web · compiladores · arquitetura de computadores · sistemas embarcados e simulação numérica.

## Tecnologias

Java, Python, JavaScript/TypeScript; Node.js/Express, Next.js e PostgreSQL; PyTorch, MediaPipe e Playwright.

## Projetos em destaque

- [Gerenciador de tarefas com Express](https://github.com/felipe-rodriguesz/CRUD_de_Tarefas_Express) — aplicação web e API com contas, tarefas, PostgreSQL e autenticação por JWT.
- [DevRoast](https://github.com/felipe-rodriguesz/devroast) — aplicação web em Next.js para analisar trechos de código com IA e consultar um ranking.
- [Compilador GYH com ANTLR](https://github.com/felipe-rodriguesz/CompiladorGYH-ANTLR) — projeto acadêmico em Java que analisa a linguagem GYH e gera código C.
- [SistemaPagamentos](https://github.com/felipe-rodriguesz/SistemaPagamentos) — aplicação desktop Java Swing para gerenciar aluguéis, reservas e pagamentos simulados.
- [LeopaNet](https://github.com/felipe-rodriguesz/LeopaNet) — coleção de projetos e experimentos de visão computacional com Python, PyTorch e MediaPipe.
- [Monitor de preços](https://github.com/felipe-rodriguesz/monitor-precos-bot) — protótipo de bot Telegram em Python que consulta preços da Amazon com Playwright.

O [GitHub](https://github.com/felipe-rodriguesz) é o principal lugar para conhecer meu trabalho; os repositórios contêm detalhes e instruções de cada projeto.
